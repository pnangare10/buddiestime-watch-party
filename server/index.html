How to get started

1
Download and install the APK. On Android, go to Settings → Install unknown apps and allow your browser or file manager.
2
Open the app, pick a streaming service, then tap the party icon and enter a room name.
3
Share the room name with friends. They open the app, enter the same room name, and everyone stays in sync automatically.

How it works

The first person to join a room becomes the host — their play, pause, and seek actions sync to all guests in real time. Guests stay within 3 seconds of the host automatically. No account needed.
